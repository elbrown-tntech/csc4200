# =============================================================================
# CSC 4200 / 5200 — .gitignore for programming assignment repositories
#
# Copy this file into your assignment repository BEFORE your first commit:
#
#     cp ~/csc4200-course/templates/assignment-gitignore \
#        ~/csc4200-work/csc4200-pa1-yourname/.gitignore
#
# Note the rename: it must be called .gitignore in your repository, with the
# leading dot. Git only reads it under that name.
#
# Why this matters: both programming assignments award 20 of 100 points for
# version control practice. A history full of compiled binaries and editor
# junk obscures the work you actually did, and a repository containing a
# virtual environment can run to hundreds of megabytes.
#
# Commit your SOURCE. Never commit what a build produces.
# =============================================================================
